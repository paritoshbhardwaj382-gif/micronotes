#  MicroNotes

A simple full-stack notes application built with the **MERN stack** (React, Node.js, Express). This project was created as part of the MERN Assignment to understand JavaScript fundamentals, REST APIs, and client-server communication.

##  Features

- Add new notes
- View all saved notes
- React frontend
- Express backend
- REST API communication using Fetch API
- Notes stored in server memory (no database)



## Technologies Used

### Frontend
- React
- Vite
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- CORS


##  API Endpoints

### GET `/api/notes`

Returns all notes.

Example Response:

```json
[
  {
    "id": 1,
    "title": "Shopping",
    "content": "Milk, Eggs",
    "createdAt": "2026-08-04T10:30:00.000Z"
  }
]
```
